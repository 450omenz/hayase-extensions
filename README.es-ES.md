# Hayase Extensions
Alternativa a [HayasexShiru Extensions](https://github.com/Rewelp/HayasexShiru-Extensions) después de que el backend dejara de funcionar; como no puedo comparar el rendimiento, no puedo garantizar que sea mejor y el proyecto está básicamente hecho "por vibras" (solo quería usar hayase gng :sob:). No conozco GitHub demasiado bien, eh, así que creé un repositorio aparte, disfrútenlo.

## Installation
Pega esta URL en Settings → Extensions → Repositories:
`https://raw.githubusercontent.com/450omenz/hayase-extensions/refs/heads/main/index.json`
o simplemente `gh:450omenz/hayase-extensions`
